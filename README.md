# Effect of Background Removal on Arabic Calligraphy Style Classification (HICMA, ResNet-18)

Course project for CAI 421 (Deep Learning). Two ResNet-18 models are trained under identical settings, one on the original HICMA images (baseline) and one on background-removed images, and compared using Accuracy, Macro-F1 and confusion matrices.

## Repository contents

|---|---|

## Data

HICMA dataset, CC BY-NC 4.0: https://hicma.net/dataset.html
Citation: A. Ismail, Z. Kamel, R. Mahmoud, "HICMA: The Handwriting Identification for Calligraphy and Manuscripts in Arabic Dataset," ArabicNLP 2023, pp. 24-32.

Expected layout after unzipping: three folders `Set1`, `Set2`, `Set3`, each containing an `images/` folder and a `labels` file. Three images with conflicting style labels (`Al-Asr_segment_no_0-2`) are excluded automatically, leaving 5,028 images in five styles.

## How to reproduce (Google Colab)

1. Upload `dataset.zip` (the HICMA download) to the root of your Google Drive (`MyDrive`).
2. Open `hicma_baseline_full.ipynb` in Google Colab and set Runtime > Change runtime type > T4 GPU.
3. Run all cells in order (Runtime > Run all). The first cell mounts Drive and unzips the data; accept the Drive permission prompt.
4. Results are written to the Colab working directory (see the table above).

Local run: `pip install -r requirements.txt`, unzip the data into `./HICMA`, and run the notebook cells from section 2 onward (skip the Drive cell).

## Settings (match the paper)

- Input 128x768 RGB, aspect ratio preserved with white padding, ImageNet normalization
- Augmentation (training only, both conditions): random rotation of +-5 degrees
- Split: stratified 80% / 10% / 10% (train / val / test), `random_state = seed`
- ResNet-18 initialized with ImageNet weights, final layer replaced by 5 outputs
- Adam, learning rate 1e-4, batch size 32, 30 epochs, cross-entropy loss
- Checkpoint with best validation Macro-F1 is evaluated once on the test set
- Fixed random seed: 42 (Python, NumPy, PyTorch, deterministic cuDNN). To repeat over several seeds, set `SEEDS = [42, 43, 44, 45, 46]` in section 2.
- Quick trial: set `N_PER_CLASS = 40` to use a small class-balanced sample instead of the full dataset.

## Background removal

The writing is kept in its original colors and everything else is replaced with white: background is estimated with a 51x51 median filter, pixels differing from it are selected with Otsu thresholding, and the mask is dilated with a 3x3 kernel. Both conditions share the same split, padding and augmentation, so they differ only in background content. Always inspect `bg_removal_preview.png`: the writing must not be erased.

## Notes and limitations

- The dataset is highly imbalanced (Naskh 74.2%; Muhaquaq has only 17 images, so about 2 per validation/test split), so Macro-F1 is the primary metric and per-class results for Kufic and Muhaquaq must be read with caution.
- Lines cropped from the same page may fall into different splits.
- A single seed gives a noisy comparison; use several seeds before drawing conclusions.
